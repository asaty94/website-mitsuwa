- **対象**: 確認用サイト `https://asaty94.github.io/website-mitsuwa/`（#22 のデプロイ時点）。スライドの修正だけは、修正後のビルドを `npx vite preview` で配信して確かめた

### 見つかった問題

- **ヒーローの背景写真が切り替わらない（全ブラウザ共通）**: 写真 4 枚とフェードの CSS はあるが、切り替える JavaScript がなく、1 枚目のまま表示されていた。STEP1 の「スライド切替する」の合格は誤りだった。`website/src/js/main.js` に 5 秒ごとに切り替える処理を加え、修正後のビルドで Edge と WebKit で 1→2→3→4→1 と切り替わること、動きを減らす設定（`prefers-reduced-motion: reduce`）では切り替わらないことを確かめた。確認用サイトへの反映は、この修正を main に取り込んだ後のデプロイで行われる。
