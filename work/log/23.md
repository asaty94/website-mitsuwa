## 起きたこと

- 作業用の Mac に Edge がなく、確認方法を担当者に聞いた。担当者の選択で Homebrew から Edge を入れ、Playwright で Edge を動かして確認した。
- STEP1 の Safari の確認で合格になっていた「ヒーロー背景写真がスライド切替する」が、実際には切り替わっていなかった。切り替える JavaScript はどのコミットにもなく、CSS と写真 4 枚だけがあった。Issue の要件「問題があれば修正するか、別の Issue にした」に沿い、処理が小さいためこの PR で直した。切り替えの間隔（5 秒）は担当者の指定がなく、こちらで決めた。
- Edge の PC 幅の初回の実行で、読み込めていない製品画像が 1 枚と出た。再実行では 13 枚とも読み込めており、遅延読み込み（`loading="lazy"`）のタイミングによるものと判断した。4xx の応答はなかった。
- 作業中に担当者から、テスト内容がどこに整理されているか質問された。テスト結果レポートに項目と結果がまとまっており、テスト項目だけの文書はないと答えた。
- スマートフォンの表示は、ブラウザの画面サイズの再現で確かめた。実機では見ていない。
- 定義の終了と実行の開始の時刻を分けて取らなかったため、1 行にまとめた。Edge の確認方法について担当者の返事を待った時間（数分）は、時刻を取らなかったため実行の所要に含まれている。
