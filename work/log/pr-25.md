# 工程表の支払いを公開後に変更

- Issue: なし
- PR: #25
- workloop: 0.4.1

## 起きたこと

- 担当者から、支払いを「公開後1か月以内」にしてはどうかと相談された。依頼者が見てから払える利点と、本番サーバーが依頼者のものなので未払いでもサイトを止められない点を伝えた。担当者の判断で、見積の承諾と確認OKの後に公開し、公開時に請求する順番にした。
- 支払期日の書き方として「1か月以内」と「翌月末」を示したが、担当者の指示は「そのように」だけだった。担当者が最初に言った「公開後1か月以内」を採り、見積書では「期日は請求書に記載します」と添えて、日付は請求書に書くことにした。
- 見積書と送付メールの文面はリポジトリの外にある。書き換える前にスクラッチパッドへ控えを取り、HTML を直して Chrome のヘッドレスで PDF を作り直した。画像にして 1 ページに収まっていることを確かめた。

## workloop への気づき

- リポジトリの外の成果物（見積書）も同じ依頼で直したが、手順にはリポジトリの外の変更の扱いがない。PR の「変更」に書いた。
