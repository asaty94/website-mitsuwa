# 問い合わせフォームの廃止とメールアドレス掲載への変更

- Issue: #20
- PR: #21
- workloop: 0.4.1

## 起きたこと

- 作業中に担当者から、完了したら体裁を確かめるためのリンクを出すよう依頼があった。GitHub Pages は main への push でしか公開されないため、ブランチの内容はローカルの `vite preview` で配信し、そのリンクを渡すことにした。
- 確認環境の Chrome ウィンドウは幅 957px より狭くできず、自ページを iframe に入れる方法も CSP の `frame-src` で止められた。スマートフォン幅の確認は Playwright で行った。
- スマートフォン幅（375px）でアドレスが「.j / p」で折り返したため、576px 以下ではアドレスの文字を小さくした。
- 電話・FAX の案内を残すという要件に合わせ、問い合わせ欄に FAX 番号を加えた。これまでこの欄には電話番号だけがあり、FAX はフッターと会社概要にだけあった。
- 実行と検証は、表示を確かめては直すことを繰り返したため、手順を分けずに 1 行で記録した。
